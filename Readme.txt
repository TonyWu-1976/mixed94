====================================================
        混合班 94（Mixed Class 94）同学录
                  浏 览 说 明
====================================================

一、如何打开
    用浏览器打开本目录下的 homepage.htm 即可进入主界面。
    （index.htm 为开场页，会自动跳转到主界面。）

二、各栏目
    · 群英谱 —— 全班同学录，点击合影上的头像进入个人主页
    · 师恩难忘 —— 老师风采与师长寄语
    · 我们的生活 —— 校园生活影像
    · 一本难忘的书 —— Remember the Time
    · 发展前瞻 —— 会场、研讨等视频
    · 离别的日子里 —— 毕业留影

三、音频与视频
    本站背景音乐、录音已转为 MP3，视频已转为 MP4，
    现代浏览器可直接播放，无需安装额外插件。

四、说明
    本站原为 1998 年制作，部分早期特效（Java Applet）
    在现代浏览器中不再支持，不影响内容浏览。
